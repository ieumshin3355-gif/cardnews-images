개인정보처리방침

시행일: 2026-10-27

  • 이 앱은 운영자 본인의 Google 계정만 사용합니다.
  • YouTube API로 하는 일: 본인 채널 정보 확인, 본인이 만든 영상 업로드, 본인 채널 댓글 확인.
  • 인증 토큰은 운영자 본인의 컴퓨터와 본인 소유 서버에만 저장하며, 다른 곳에 판매·공유하지 않습니다.
  • Google API로 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 권한은 Google 계정 권한 페이지에서 언제든 해제할 수 있습니다.

Privacy Policy (English)

  • This app is used only with the operator's own Google account.
  • It uses the YouTube API to read the operator's channel info, upload the operator's own videos, and read comments on the operator's channel.
  • Auth tokens are stored only on the operator's own computer and server and are never sold or shared.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.
